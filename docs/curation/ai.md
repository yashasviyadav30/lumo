## Syllabus source

There is no official AI syllabus. The outline below is **our own short outline**, built from open course outlines:

- NPTEL Introduction to Machine Learning, IIT Madras (Prof. Balaraman Ravindran, 12 weeks): https://www.cse.iitm.ac.in/~ravi/nptel-courses/intro-to-machine-learning/
- Stanford CS229 syllabus (Fall 2022): https://cs229.stanford.edu/syllabus-fall2022.html
- NPTEL Deep Learning Part 1, IIT Madras (noc19_cs85): https://onlinecourses.nptel.ac.in/noc19_cs85/preview
- NPTEL Introduction to LLMs, IIT Delhi: https://nptel.ac.in/courses/106102576
- CampusX "100 Days of ML" outline (public notes page)

Notes: "data science" overlaps with Foundations and Machine learning. "AI" alone is vague; the app handles that.

## Topic map (4 levels, 29 topics)

- **Foundations for AI** (`ai-fnd-foundations`)
  - Python programming (`ai-fnd-python`)
  - Working with data in Python (NumPy, pandas, plots) (`ai-fnd-data-tools`)
  - Linear algebra for ML (`ai-fnd-linalg`)
  - Calculus and optimisation for ML (`ai-fnd-calculus`)
  - Probability and statistics (`ai-fnd-probstats`)
- **Machine learning** (`ai-ml-machine-learning`)
  - What ML is and its types (`ai-ml-intro`)
  - Data preparation, EDA and feature engineering (`ai-ml-data-prep`)
  - Regression (`ai-ml-regression`)
  - Classification (logistic regression, trees, SVM, k-NN, naive Bayes) (`ai-ml-classification`)
  - Ensembles (random forest, boosting, XGBoost) (`ai-ml-ensembles`)
  - Unsupervised learning (clustering, PCA) (`ai-ml-unsupervised`)
  - Model evaluation and tuning (metrics, bias-variance) (`ai-ml-evaluation`)
  - Reinforcement learning basics (`ai-ml-rl`)
  - Classic AI (search, logic, planning) (`ai-ml-classic-ai`)
- **Deep learning** (`ai-dl-deep-learning`)
  - Neural network basics (perceptron, backpropagation) (`ai-dl-nn-basics`)
  - Training deep nets (optimisers, regularisation) (`ai-dl-training`)
  - CNNs and computer vision (`ai-dl-cnn`)
  - RNNs and sequence models (LSTM, GRU) (`ai-dl-rnn`)
  - Attention and transformers (`ai-dl-transformers`)
  - Deep learning frameworks (PyTorch, TensorFlow) (`ai-dl-frameworks`)
- **LLMs and applied AI** (`ai-llm-llms-applied-ai`)
  - NLP basics (text processing, word embeddings) (`ai-llm-nlp-basics`)
  - How LLMs work (pretraining, GPT, tokenisation) (`ai-llm-how-llms`)
  - Fine-tuning and alignment (LoRA, RLHF) (`ai-llm-finetune`)
  - Prompting, RAG and agents (`ai-llm-prompt-rag`)
  - Building and deploying ML/AI apps (MLOps) (`ai-llm-deploy`)
